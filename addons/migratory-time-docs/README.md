# Migratory Time for Feishu Docs

飞书云文档正文小组件。一个组件代表一个时间节点；文档编辑者可点击任一地区的时间直接修改同一时刻，并通过地球图标选择本组件显示的地区。语言是每位查看者的本地偏好，不会改动其他人的文档内容。

地区选择使用飞书文档级 `modal` 视图，不受正文小组件自身窄视口限制。共享数据只保存时间节点、阶段名称和显示地区；组件不读取或改写周围 PRD，也不使用 AI 或后端服务。

## 当前发布边界

源码和本地构建已经就绪，但 `app.json` 中的 `appID`、`blockTypeID` 必须由目标飞书租户创建小组件时生成。不要填入公司租户 ID；本项目按所有者要求只接受个人身份创建。

个人身份创建成功后：

```bash
npm install
npm run build
npm run upload
```

上传和发布仍需按飞书开放平台的小组件发布流程操作。
