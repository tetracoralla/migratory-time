## 已实现

`addons/migratory-time-docs/` 基于飞书官方 `docs-addon` 模板和 `@lark-opdev/block-docs-addon-api`：

- 正文块内直接展示选中地区的时间。
- 文档编辑者点击任一地区时间即可修改同一时刻。
- 阶段名称、时刻和显示地区通过组件 Record 作为协作数据保存。
- 语言按查看者本地保存，并优先跟随飞书客户端语言。
- 语言与地区图标并列；地区选择通过 `View.Action.openModal` 打开文档级模态框。
- 查看者没有文档编辑权限时，时间和地区配置入口为只读，语言仍可切换。
- 复用网页的地区配置、IANA/Temporal 换算与输入解析，不使用第二套时区规则。
- 不需要后端、数据库、OpenAPI User Access Token 或 AI 额度。

## 与 PRD 的关系

一个组件管理一个时间节点。开始、倒计时、预热、正式发布、结束等阶段可以分别插入组件；每个组件只管理自己的阶段名称、时刻和地区，不定义或改写需求中的市场范围。需要美国单区、欧洲或全球联动时，由文档编辑者在该组件的地区模态框中选择。
