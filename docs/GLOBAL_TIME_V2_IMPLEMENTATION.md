# Migratory Time 2.0 历史实施锚点

本文件只保留 2.0 全球时区阶段的历史产品边界，不能作为当前源码、安装、分发或
发布状态的依据。当前边界由 `product-model.md` 定义，当前复核方法由
`REVIEW_CONTRACT.md` 定义，运行结论必须从对应命令和载体重新取得。

## 目标系统状态

Migratory Time 成为面向人和 Agent 的全球民用时间换算工具。网页、MCP、
Codex 插件和实验性 Capability 适配器共用一个确定性核心，可处理全球 IANA
时区、当地名称搜索、夏令时重复与不存在时刻、分钟精度边界、旧分享链接兼容
和有界结构化结果。

飞书云文档小组件保留源码，但标记为暂缓集成，不属于 2.0 完成线，也不参与
主产品发布结论。

## 完成线

- 网页默认仍显示现有五个常用地区，同时可搜索、添加、移除和持久化全球地区。
- `convert_time` 和 `current_times` 对合法 IANA 标识、稳定别名和无歧义地点名称
  保持一次调用；真正歧义返回候选而不猜测。
- `search_time_zones` 紧凑返回候选；旧 `list_time_zones` 作为兼容入口保留，
  不一次倾倒完整全球目录。
- MCP 成功分支使用严格判别联合；错误包含稳定结构化代码、字段、输入和候选。
- 旧五地区别名、偏好和分享短码继续可读；新分享链接支持任意 IANA 时区。
- IANA/CLDR 元数据来源、运行时规则数据版本和分钟精度限制可被检查。
- Capability Profile 保持 provider-seeded experimental，只包含规范 IANA 换算语义，
  不吸收产品标签、搜索、复制文本或分享链接。
- 当前源码通过开发回归；新安装插件在冷会话中通过普通中英文请求选择正确工具，
  记录调用次数且不使用 Web、Shell 或模型手算；网页通过桌面、手机、键盘、分享、
  持久化、错误恢复和离线复验。

## 产品与交互对象

- `时区`：规范 IANA 标识、国家/地区、主要城市、稳定别名和本地化显示名称。
- `显示地区`：用户当前列表中有序且唯一的时区集合，至少一项。
- `时刻`：实时或固定的 `Temporal.Instant`。
- `当地时间输入`：来源时区中的日期时间，可能有效、重复、不存在或超出分钟精度。
- `分享快照`：固定时刻和有序显示地区；语言仍属于查看者偏好。

地区选择器是页面级对话框。搜索只缩小候选，不改变选择；选择动作立即更新列表和
本地偏好；关闭、`Esc` 和点击遮罩返回原页面操作点。默认列表不增加说明面板。

## Agent 路由预算

- 普通“现在几点”或明确换算：一个领域工具调用。
- 无歧义城市、国家主时区、现有中英文别名：不先搜索。
- 地点或缩写存在真实歧义：一次结果返回候选，由用户选择后再调用。
- 显式询问支持项或探索地点：一次 `search_time_zones`。
- 非法输入：一次稳定错误，不重试，不回退到通用工具。

## 非目标

- 节假日、工作日、日出日落、航班、日历账号、会议写入和提醒。
- 跨提供者替代性声明；当前只有一个 provider-seeded experimental Profile。
- 飞书上传、租户、管理员或市场审核。
- 为全球目录增加独立管理后台、账户或云数据库。
